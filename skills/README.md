# Skills para Workspace Landings

Este directorio contiene skills de Claude para mejorar el desarrollo de landings.

## frontend-design

**Descripción:** Crea interfaces frontend distintivas y de alta calidad que evitan estéticas genéricas de IA.

**Cuándo usar:**
- Cuando necesites diseñar una nueva landing page
- Para crear componentes visuales únicos
- Cuando quieras un diseño audaz y memorable

**Cómo usar:**

1. **Contexto al prompt:**
```
Usando la skill frontend-design, crea una landing para [tipo de negocio] con tonos [colores].
```

2. **La skill te guiará a:**
   - Elegir una dirección estética BOLD
   - Seleccionar tipografías únicas
   - Crear paleta de colores cohesiva
   - Implementar animaciones profesionales
   - Diseñar layouts inesperados

3. **Output esperado:**
   - Código Astro + Tailwind + GSAP
   - Diseño distintivo y memorable
   - Performance optimizado
   - Production-ready

## Workflow Recomendado

1. **Planificación:**
   - Define el concepto visual
   - Elige paleta de colores
   - Decide tipografías

2. **Desarrollo:**
   - Skill frontend-design genera componentes
   - Implementa en Astro
   - Añade animaciones GSAP

3. **Optimización:**
   - Descarga imágenes localmente
   - Optimiza para mobile
   - Test performance

4. **Deploy:**
   - Build estático
   - Deploy a Vercel/Netlify
   - Verifica en producción

---

**Stack del workspace:**
- Framework: Astro
- Styling: Tailwind CSS
- Animations: GSAP
- Fonts: Google Fonts (únicas, no genéricas)
